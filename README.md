# Dachshund Care App

Уютное mobile-first веб-приложение, в котором реальные действия по уходу за таксой превращаются в мягкий игровой прогресс.

## Что уже работает

- первый запуск с вводом имени питомца;
- адаптивный главный экран для телефона и компьютера;
- будний и выходной шаблоны дня;
- ежедневные задачи и быстрые отметки действий;
- косточки за выполненные действия и монетки за полностью закрытый день;
- реакция комнаты и персонажа на дневной прогресс;
- локальное сохранение профиля, плана и наград между перезагрузками;
- базовая навигация по разделам Дрессировка, Приключения, История и Ещё;
- CI через GitHub Actions: lint, typecheck, tests и production build.

## Технологии

React 19, TypeScript, Vite, React Router, Oxlint и Vitest.

## Запуск локально

Требуется Node.js 22.18+.

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## Архитектура

```text
src/
  components/   переиспользуемые UI-компоненты
  domain/       типы и шаблоны дневных планов
  game/         игровая бизнес-логика
  pages/        экраны приложения
  services/     хранение и внешние зависимости
```

Текущее локальное хранилище вынесено в `services/storage.ts`, поэтому его можно заменить IndexedDB или облачной базой без привязки бизнес-логики к React-компонентам.

## Ближайшие рабочие срезы

1. Настоящая библиотека команд и журнал тренировок.
2. Доска приключений с загрузкой фотографий через IndexedDB.
3. История завершённых дней и вечерний итог.
4. Карточки знаний и достижения.
5. Расширение состояний и анимаций пиксельной таксы.
