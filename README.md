# Motya - Dachshund Life Simulator

Mobile-first игровое веб-приложение про жизнь с таксой Мотей. Реальные действия по уходу превращаются в мягкий игровой прогресс, а главным экраном остаётся интерактивная сцена с самой собакой.

## Что уже работает

- первый запуск с вводом имени питомца;
- большая HD-сцена комнаты на главном экране вместо dashboard-сетки;
- прямое взаимодействие с Мотей: нажатие на персонажа вызывает реакцию;
- действия внутри сцены: кормление, вода, прогулка, игра и тренировка;
- будний и выходной шаблоны дня;
- ежедневные задачи, косточки за действия и монетки за полностью закрытый день;
- компактный HUD поверх игровой сцены и ближайшая цель дня;
- мягкий параллакс, реакционные эффекты и анимация наград/сердечек;
- локальное сохранение профиля, плана и наград между перезагрузками;
- базовая навигация по разделам Дрессировка, Приключения, История и Ещё;
- адаптивный mobile-first интерфейс;
- CI через GitHub Actions: audit, lint, typecheck, tests и production build;
- автоматический deploy на GitHub Pages со smoke-test опубликованной сцены и игровых ассетов.

## Визуальная система

Текущая версия использует сгенерированную тёплую 3D / 2.5D сцену и отдельный 3D UI atlas из `public/assets/art/v5/`. Пиксельный визуальный слой больше не является направлением продукта.

Следующий визуальный этап - расширить единый образ Моти по реальным фотографиям: состояния, эмоции, сон, ожидание прогулки, игра, тренировка и взаимодействие с предметами комнаты.

## Технологии текущей версии

- React 19;
- TypeScript;
- Vite;
- React Router;
- Oxlint;
- Vitest;
- CSS-слои для игровой сцены и адаптивного интерфейса.

Архитектура остаётся подготовленной к следующим этапам: Zustand для игрового состояния, IndexedDB для воспоминаний и фотографий, Motion для интерфейсных анимаций и React Three Fiber / Three.js для дальнейшего усиления глубины сцены или подключения rigged 3D-модели Моти.

## Запуск локально

Требуется Node.js 22.18+.

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## Архитектура

```text
src/
  components/   игровая сцена и переиспользуемые UI-компоненты
  domain/       типы и шаблоны дневных планов
  game/         игровая бизнес-логика и прогресс
  pages/        игровые разделы приложения
  services/     хранение и внешние зависимости
```

Текущее локальное хранение вынесено в `services/storage.ts`, поэтому его можно заменить на IndexedDB и позднее на облачную синхронизацию без привязки бизнес-логики к React-компонентам.

## Следующие рабочие срезы

1. Зафиксировать character bible Моти по реальным фотографиям и расширить набор её состояний.
2. Сделать тренировку полноценной мини-игрой с этапами освоения команд и журналом тренировок.
3. Реализовать Доску приключений с загрузкой реальных фотографий через IndexedDB.
4. Добавить инвентарь, магазин и предметы, которые действительно появляются в комнате.
5. Реализовать вечерний итог, историю завершённых дней и памятные события.
6. Добавить Таксячью энциклопедию, достижения и коллекционные награды.

Главный критерий каждого следующего изменения: приложение должно усиливать желание взаимодействовать с Мотей, а не превращаться в интерфейс учёта ухода.
