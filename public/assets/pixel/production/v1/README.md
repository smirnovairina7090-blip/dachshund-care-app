# Pixel production assets v1

Эти PNG-атласы собраны непосредственно из утверждённого сгенерированного pixel-art asset sheet. Фигуры не перерисовывались CSS/SVG-примитивами: элементы вырезаны из generated artwork, фон удалён, пиксельная графика сохранена и оптимизирована для веб-приложения.

Файлы:
- `dog-states.png` - 12 состояний таксы;
- `care-icons.png` - корм, вода, поводок, игра, тренировка, щётка, сон, ласка, фото, ветеринар, уход и обучение;
- `navigation.png` - главная, тренировка, приключения, история, ещё;
- `currency-effects.png` - косточка, монетка, сердце и 6 кадров хвоста;
- `room-props.png` - диван, растение с тумбой, окно и лежанка;
- `manifest.json` - координаты всех спрайтов внутри атласов.

Для рендера используем `image-rendering: pixelated`. Эти файлы являются текущей production-базой визуала; большие сгенерированные листы хранятся отдельно как reference previews.
