# Generated Pixel Visual Pack v1

Визуальная система приложения основана на сгенерированном pixel-art контенте, который был утверждён в чате. Самодельный SVG из геометрических примитивов удалён и больше не является частью asset pack.

## Production assets

Готовые для приложения прозрачные PNG-атласы лежат в `public/assets/pixel/production/v1/`:

- `dog-states.png` - 12 состояний таксы;
- `care-icons.png` - 12 действий и предметов ухода;
- `navigation.png` - 5 иконок нижней навигации;
- `currency-effects.png` - косточка, монетка, сердце и кадры хвоста;
- `room-props.png` - предметы комнаты;
- `manifest.json` - координаты спрайтов.

Они получены непосредственно из утверждённого generated asset sheet: элементы вырезаны из изображения, фон удалён, пиксельная графика сохранена. Никакой замены изображений CSS/SVG-примитивами здесь нет.

## Reference previews

Уменьшенные копии больших сгенерированных листов для просмотра в GitHub находятся в `docs/visual/generated/v1/`. Они нужны как художественный source of truth, а в интерфейсе используем production-атласы из `public/assets/pixel/production/v1/`.

Следующий этап - подключение этих спрайтов к компонентам приложения и визуальная переделка онбординга, главной комнаты и нижней навигации без расширения продуктового функционала.
